Glosario

Este glosario define los términos principales utilizados en el manual:

  • Botón de emergencia: Botón físico que, al presionarlo, inicia una llamada de emergencia.
  • Tótem: Dispositivo Android tipo tótem digital que actúa como punto de interacción para el usuario y despliega publiidad.
  • Receptor: Persona que recibe la llamada SOS (por ejemplo, personal médico o paramédico).
  • App ApantallaNet: Aplicación que gestiona la reproducción de publicidad en el tótem.
  • App KairosLauncher: Aplicación responsable de instalar y gestionar los scripts que controlan la llamada y el reinicio automático de los procesos.

Hardware necesario

Por cada tótem, se requiere el siguiente hardware mínimo para la correcta instalación de MediKairos:

  • Botón de emergencia (FootSwitch USB).
  • Micrófono USB.
  • Hub USB con al menos 4 puertos y un cable de 1m para facilitar el acceso desde la parte trasera del tótem.
  • Mouse y teclado USB (preferentemente inalámbricos o con receptor único). No se recomienda el uso de dispositivos Bluetooth para el mouse o teclado.
  • Un teléfono móvil con línea activa para recibir SMS (requerido durante la configuración de Signal).

Instalación — Resumen de pasos

Los pasos generales para la instalación son los siguientes:

  1. Conectar el hardware necesario.
  2. Instalar y configurar la aplicación Signal en el tótem y en el dispositivo del receptor.
  3. Instalar y configurar aplicación KairosLauncher.
  4. Verificar la instalación y realizar pruebas de funcionamiento.

Paso 1 — Conectar el hardware

Siga los pasos a continuación para conectar correctamente el hardware en el tótem:

  1. Abrir la carcasa del tótem y conectar el hub USB en uno de los puertos disponibles. Se recomienda pasar el cable del hub por la compuerta trasera para que el hub quede accesible desde la parte posterior.
  2. Conectar el teclado y el mouse al hub USB.
  3. Conectar el Botón de emergencia al hub USB.
  4. Conectar el micrófono USB al hub.
  5. Conectar el tótem a internet con un cable Ethernet a la ranura de la base. ⚠️ Es importante que el totem este conectado a internet durante la instalación, pruebas y operación de MediKairos
  6. Conectar el tótem a la corriente eléctrica para encenderlo.

Verifique visualmente que los indicadores del hardware estén activos y que el sistema reconozca los dispositivos conectados.

Es importante que el totem este conectado a internet durante la instalación, pruebas y operación de MediKairos

Paso 2 — Instalar y configurar Signal

Este paso incluye la configuración de Signal tanto en el tótem como en el teléfono del receptor.

Configurar Signal en el tótem

  1. Desde el tótem, abra Google Play Store e instale la aplicación Signal.
  2. Siga las instrucciones de la aplicación para registrar el número: introduzca el código de confirmación recibido por SMS.
  3. Asigne el PIN de Signal: 112233.
  4. En la pestaña Chats, cree un nuevo chat con el número del receptor y envíe el mensaje: "Bienvenido a MediKairos". Verifique que la conversación aparezca en la parte superior de la lista de chats.
Nota: Para descargar Signal debe existir una sesión activa en Google Play Store. Las credenciales se las proporcionará el equipo de desarrollo.

Configurar Signal en el receptor

  1. Instale la aplicación de Signal en el teléfono del receptor desde la Play Store.
  2. Al recibir el mensaje de bienvenida desde el tótem, el receptor debe aceptar o confirmar el contacto para habilitar la recepción de llamadas.
Importante: Si el receptor no acepta la conversación, las llamadas no se podrán enlazar correctamente.

Paso 3 — Instalar KairosLauncher

Para instalar KairosLauncher en el tótem:

  1. Abra Chrome en el tótem y visite la página de descargas https://yessmiguel.github.io/kairos-builds/ proporcionada por el proveedor del sistema.
  2. Pulse el botón de descarga correspondiente a la versión de KairosLauncher.
  3. Siga las instrucciones de instalación del paquete APK en Android.

Una vez instalado, confirme que la aplicación aparece en la lista de aplicaciones del tótem.

Paso 4 — Verificar la instalación

Complete la siguiente lista de verificación para confirmar que la instalación fue exitosa:

  • ✅ Micrófono conectado al hub USB y funcionando.
  • ✅ Botón de emergencia conectado al hub USB
  • ✅ Aplicación Signal instalada y configurada, con la conversación del receptor visible y activa en la pestaña de chats, corroborar ademas que es la primera conversación de la lista.
  • ✅ App KairosLauncher instalada y visible en la lista de aplicaciones.
  • ✅ Reiniciar el tótem. Luego, confirmar que la publicidad se inicia automáticamente. Luego,realizar una prueba de llamada con el botón.
  • 🚀 Si la llamada se realiza correctamente, la instalación se ha completado con éxito.
Una vez instalados los primeros tres pasos, hay que reiniciar el totem una vez para que las configuraciones pueden surtir efecto.
En caso de fallas o incovenientes ir a la seccion de troubleshooting
En cada reninicio del tótem se debe de esperar hasta que se lance la publicidad para poder iniciar una prueba de llamada.

Apéndice A - Troubleshooting

Problemas comunes y acciones recomendadas:

  • La llamada inicio y aparece el mensaje "Error de conexión" en Signal: Asegurar que el totem se encuentra conectado a Internet por el puerto Ethernet en la base, si persiste el problema abrir la carcasa para verificar que el cable Ethernet esta conectada en la compuerta trasera del totem. Finalmente reiniciar el tótem
  • La llamada inicio y aparece el mensaje "Tu cámara está desactivada" en Signal: Asegurar que el tótem se encuentra conectado a Internet por el puerto Ethernet en la base, si persiste el problema abrir la carcasa para verificar que el cable Ethernet esta conectada en la compuerta trasera del totem. Finalmente reiniciar el tótem
  • Rendimiento interrumpido o la app se congela: Reinicie el tótem. Si el problema persiste, notifique a soporte y considere reinstalar la app.
  • La aplicación se congela durante la llamada: Apague el tótem, compruebe la conexión de red por el puerto Ethernet de la base — utilice una red WLAN estable con un mínimo de 80 Mbps. Reinicie el tótem.
  • Los scripts no se ejecutan por lentitud: Reinicie el tótem.
  • Totem desconectado de la red: Reconectar el cable de red Ethernet a la base, verificar la conexión a internet y reiniciar el tótem.
  • La llamada se reinicia en bucle: Verificar que el Botón de emergencia y el micrófono estén correctamente conectados; reiniciar el tótem.
  • La llamada no se puede concretar porque la aplicación Signal cambió su interfaz: Reinicie el tótem y si el problema persiste contacte al equipo de desarrollo.
  • Botón o cablería del botón visiblemente dañada: Reemplace el botón o el cable según corresponda y reinicie el tótem

Apéndice B - Operación del tótem

Este es el resumen de operaión del totem

  • Prender el tótem: Se prende el totem conectando el cable de corriente de la base
  • Apagar el tótem: Se prende el totem desconectando el cable de corriente de la base
  • Reiniciar el totem: Se reinicia el totem deconectando el cable y volviendo a conectar
  • Abrir carcasa: El tótem tiene dos llaves de seguridad de lado izquierdo, para abrir cada una de ellas: Insertar la llave, girar a la derecha hasta notar el tope (giro completo) y esperar a que el perno se bote por completo. Una vez desplegado el perno, tirar (jalar) suavemente para abrir la tapa. Se recomienda no forzar la tapa ya que esta debe salir fácilmente
  • Cerra carcasa: Juntar la carcasa hasta que quede bien pegada y simplemente empujar hacia adentro cada botón
  • Barra de inicio desaparece: Si se desaparece la barra de inicio (barra negra con iconos blancos) basta con dezplazar rapidamente el cursos hacia abajo para que vuelva aparecer

Resumen rápido

Objetivo: Instalar y verificar el sistema MediKairos en un tótem Android para permitir llamadas SOS entre el tótem y un receptor.

Tiempo estimado de instalación: 30–45 minutos por tótem (dependiendo de la familiaridad del instalador con Android).
